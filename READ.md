# College Management System

## Internship Project

### Overview

College Management System is a full-stack web application developed to manage colleges, students, departments, courses, and faculty through a centralized dashboard.

### Features

* Secure Login Authentication
* Dashboard Analytics
* College Management
* Student Management
* Department Management
* Course Management
* Faculty Management
* CRUD Operations
* MongoDB Atlas Integration

### Technology Stack

Frontend:

* React
* Vite

Backend:

* FastAPI
* Python

Database:

* MongoDB Atlas

### Modules

1. Dashboard
2. Colleges
3. Students
4. Departments
5. Courses
6. Faculty
